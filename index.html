Advanced Capstone Project · NYU Shanghai

Jun 2026 — presentOngoing research

LLM Test Reliability & Cross-Model Fault Detection

Serendipity Research Group · NYU Shanghai

Studying how same-model and cross-model tests expose faults in fixed code candidates, with and without access to candidate code. Built isolated execution and a proxy oracle requiring agreement among three qualified reference programs.

A 36-problem expansion yielded 52 qualified faulty programs across 21 problems for strict test-strategy comparisons; fault detection and structural coverage are analyzed separately.
