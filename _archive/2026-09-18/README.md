# Homepage snapshot before the September 18, 2026 redesign

This directory preserves the complete previous site: `index.html`, `cv.pdf`,
`CodeFORGE.pdf`, and `mygo-report.pdf`. All four files are unchanged copies.
`checksums.json` records their original SHA-256 hashes.

Open `index.html` locally, or visit `/_archive/2026-09-18/` on the local preview
server, to compare the previous design. The archived page still displays its
original “Last updated: April 2026” date.

GitHub Pages excludes this directory through `_config.yml`.

To restore the previous site, first preserve any newer work, then copy these
four files to the repository root, replacing the corresponding files. The
new `assets/` directory and `resume.pdf` can remain; the old page does not use them.
